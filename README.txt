AI FITNESS COACH - COMPLETE DEMO
Flow:
Signup -> Firebase creates account/profile -> Login page -> Login -> User Dashboard.

Signup fields:
name, email, password, age, height, weight, goal (Weight loss), activity level, workout preference.

Dashboard:
Dashboard, Daily Routine, Plans, Habit Tracker, AI Chatbot, My Profile.

Firebase:
Authentication Email/Password + Realtime Database.
Profile path: users/{uid}

Important:
Enable Authentication > Sign-in method > Email/Password.
Enable Realtime Database.
Run with VS Code Live Server, not file://.
This frontend intentionally provides general wellness guidance rather than individualized medical or weight-loss prescriptions.
